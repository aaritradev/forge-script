## 📖 Overview

ForgeScript is an AI-powered platform designed to help creators generate high-retention scripts for short-form content.

Users simply provide a topic or idea, and ForgeScript generates structured scripts optimized for platforms like YouTube Shorts, Instagram Reels, and TikTok. The platform also includes AI-assisted captions, hashtags, and multiple script variations to speed up the content creation process.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/forge-script.git
```

Install dependencies

```bash
npm install
```

Create an environment file

```env
DATABASE_URL=

NEXTAUTH_SECRET=

GOOGLE_CLIENT_ID=

GOOGLE_CLIENT_SECRET=

GEMINI_API_KEY=

GROQ_API_KEY=
```

Run the development server

```bash
npm run dev
```
